# 📸 Фотозона v2.0 — Профессиональная ретушь фотографий

![Фотозона](https://img.shields.io/badge/Фотозона-v2.0-amber?style=for-the-badge)
![Лицензия](https://img.shields.io/badge/Лицензия-MIT-green?style=for-the-badge)
![Платформа](https://img.shields.io/badge/Платформа-Windows%20%7C%20Web-blue?style=for-the-badge)

Бесплатное веб-приложение для профессиональной ретуши фотографий с интерфейсом в стиле Adobe Photoshop.

---

## ✨ Возможности

### 🎨 7 модулей обработки:

| Модуль | Функции |
|--------|---------|
| **🧴 Кожа** | Сглаживание, частотное разделение, выравнивание тона, удаление дефектов |
| **😊 Лицо** | Dodge & Burn, отбеливание зубов, удаление дефектов, чёткость |
| **👁 Глаза** | Усиление, яркость, контраст, чёткость |
| **🎨 Цвет** | Авто-баланс, насыщенность, температура, контраст |
| **💎 Детали** | Резкость, шумоподавление, чёткость, частотное разделение |
| **☀️ Свет** | Яркость, контраст, Dodge & Burn, чёткость |
| **✨ Эффекты** | Виньетка, температура, насыщенность, контраст, резкость |

### ⚡ Функции:
- **Drag & Drop** загрузка изображений
- **Реалтайм обработка** с debounce 200мс
- **25+ пресетов** (Лёгкая, Студийная, Кино, Ретро, HDR и др.)
- **Система вариантов** — сохранение/загрузка наборов настроек
- **Кнопка «Оригинал»** — переключение для сравнения
- **Масштабирование** 10–400%
- **Экспорт** в PNG/JPEG
- **16 параметров** обработки с собственными алгоритмами
- **Автомасштабирование** изображений до 4096px для производительности
- **Обработка ошибок** при загрузке повреждённых файлов

## 📦 Сборка .exe для Windows

### Способ 1: Автоматическая сборка (рекомендуется)

1. Убедитесь, что установлен **Node.js** (v18+) с https://nodejs.org/
2. Запустите скрипт сборки:

```bash
# Windows
build-exe.bat

# Linux/Mac
chmod +x build-exe.sh && ./build-exe.sh
```

3. Готовые .exe файлы появятся в папке `output/`

### Способ 2: Ручная сборка

```bash
# 1. Сборка веб-приложения
npm run build

# 2. Создание Electron окружения
mkdir electron-build
cp electron-main.js electron-build/main.js
cp electron-package.json electron-build/package.json
cp -r dist electron-build/dist

# 3. Установка зависимостей
cd electron-build
npm install

# 4. Сборка .exe
npm run electron:build
```

### Результат сборки:

В папке `electron-build/release/` появятся:
- `Фотозона Setup 2.0.0.exe` — установщик с мастером установки
- `FotoZona-Portable.exe` — портативная версия (без установки)

## ✨ Возможности

### 🧴 Ретушь кожи
- Частотное разделение (Frequency Separation)
- Сглаживание кожи с сохранением текстуры
- Выравнивание тона кожи
- Удаление дефектов и прыщей
- Уменьшение пор

### 😊 Коррекция лица
- Dodge & Burn (осветление и затемнение)
- Отбеливание зубов
- Усиление глаз
- Скульптурирование лица
- Устранение теней

### 🤖 Генеративные AI-функции
- **Генеративное заполнение** — добавление объектов по текстовому описанию
- **Генеративное расширение** — расширение изображения за пределы кадра
- **Генеративное удаление** — удаление объектов с авто-определением

### 🎨 Цветокоррекция
- Яркость, контраст, насыщенность

- Тени и света

### 🔧 Инструменты
- Резкость (Unsharp Mask)
- Шумоподавление
- Чёткость (Clarity)
- Текстура
- Виньетка
- Зерно плёнки

### 📦 Пресеты
- **Кожа**: Лёгкая, Средняя, Студийная, Портрет, Бьюти, Натуральная
- **Лицо**: Натуральный, Гламур, Модельный, Журнальный
- **LUT**: Кино, Винтаж, Тёплый, Холодный, Мрачный, Светлый, Выцветший, Teal&Orange

## 📥 Установка

### Способ 1: Через UXP Developer Tool (рекомендуется)

1. **Скачайте плагин**
   - Откройте веб-приложение Фотозона
   - Нажмите кнопку "Скачать FotoZona-Pro-v2.0.uxp-plugin.zip"
   - Распакуйте архив в любую папку

2. **Установите UXP Developer Tool**
   - Скачайте с [developer.adobe.com/photoshop/uxp/2022/guides/devtool/](https://developer.adobe.com/photoshop/uxp/2022/guides/devtool/)
   - Установите и запустите

3. **Добавьте плагин**
   - В UXP Developer Tool нажмите **"Add Plugin"**
   - Выберите файл `manifest.json` из распакованной папки
   - Плагин появится в списке

4. **Загрузите в Photoshop**
   - Убедитесь, что Photoshop 2023+ запущен
   - В UXP Developer Tool нажмите **"Load"** рядом с плагином
   - Или нажмите **"Watch"** для автозагрузки при запуске PS

5. **Откройте панель**
   - В Photoshop: **Меню → Плагины → Фотозона Pro**
   - Или: **Окно → Плагины → Фотозона Pro**

### Способ 2: Постоянная установка (.ccx файл)

1. Выполните шаги 1-3 из Способа 1
2. В UXP Developer Tool нажмите **"Package"**
3. Выберите место сохранения `.ccx` файла
4. Дважды кликните на `.ccx` файл для установки
5. Плагин будет установлен навсегда

## 🚀 Использование

### Ретушь кожи
1. Откройте изображение в Photoshop
2. Выберите слой для ретуши
3. Откройте панель **Фотозона Pro**
4. Перейдите на вкладку **"Кожа"**
5. Настройте параметры или выберите пресет
6. Нажмите **"Применить"**

### Генеративное заполнение
1. Создайте выделение области для заполнения
2. Перейдите на вкладку **"AI"**
3. Введите описание в поле "Генеративное заполнение"
4. Выберите стиль и качество
5. Нажмите **"Генерировать"**

### Генеративное расширение
1. Перейдите на вкладку **"AI"**
2. В разделе "Генеративное расширение" укажите проценты расширения
3. Нажмите **"Расширить"**

### Генеративное удаление
1. Создайте выделение объекта для удаления (или включите авто-определение)
2. Перейдите на вкладку **"AI"**
3. Нажмите **"Удалить объект"**
