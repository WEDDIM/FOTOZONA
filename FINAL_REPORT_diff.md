## 🎨 Функционал плагина

### Модули ретуши (5 вкладок):

#### 1. ✨ Кожа
- Сглаживание (Surface Blur)
- Частотное разделение (Gaussian Blur + Apply Image)
- Выравнивание тона кожи
- Удаление дефектов (Median Filter)
- Уменьшение пор

**Пресеты:** Лёгкая, Средняя, Студийная, Портрет, Бьюти

#### 2. 😊 Лицо
- Dodge & Burn (50% Gray + Overlay)
- Отбеливание зубов (Selective Color)
- Усиление глаз (Brightness/Contrast)
- Скульптурирование

**Пресеты:** Натуральный, Гламур, Модельный, Журнальный

#### 3. 🤖 AI (Генеративные функции)
- **Генеративное заполнение** — Content-Aware Fill с текстовым промптом
- **Генеративное расширение** — расширение холста с AI-заполнением
- **Генеративное удаление** — удаление объектов с авто-определением (Select Subject)

**Настройки AI:**
- Стиль: Авто, Фото, Арт
- Качество: Стандарт, Высокое, Ультра
- Авто-определение объектов

#### 4. 🎨 Цвет
- Яркость, Контраст
- Насыщенность (Hue/Saturation)
- Температура (Color Balance)
- Тени, Света (Levels)

**LUT-пресеты:** Кино, Винтаж, Тёплый, Холодный, Мрачный, Светлый, Выцветший, Teal&Orange

#### 5. 🔧 Инструменты
- Резкость (Unsharp Mask)
- Шумоподавление
- Чёткость (High Pass + Overlay)
- Текстура
- Виньетка (Lens Correction)
- Зерно (Add Noise)

## 🔧 Технические детали

### Photoshop API интеграция:
```javascript
const { app, action, core } = require('photoshop');

// Пример использования batchPlay
await core.executeAsModal(async () => {
  await action.batchPlay([{
    _obj: 'gaussianBlur',
    radius: 5
  }], {});
}, { commandName: 'Фотозона: Размытие' });
```

### Ключевые функции Photoshop API:
- `action.batchPlay()` — выполнение команд Photoshop
- `core.executeAsModal()` — модальный контекст для операций
- `app.activeDocument` — доступ к активному документу
- Content-Aware Fill — основа для AI-функций
- Select Subject — авто-определение объектов
- Frequency Separation — профессиональная ретушь кожи

### UXP Manifest v5:
```json
{
  "manifestVersion": 5,
  "host": [{ "app": "PS", "minVersion": "24.0.0" }],
  "requiredPermissions": {
    "localFileSystem": "fullAccess",
    "network": { "domains": ["all"] }
  }
}
```

## 📥 Как использовать

### Для конечных пользователей:
1. Откройте веб-приложение Фотозона Pro
2. Нажмите "Скачать FotoZona-Pro-v2.0.uxp-plugin.zip"
3. Распакуйте архив
4. Откройте UXP Developer Tool
5. Добавьте плагин через "Add Plugin"
6. Нажмите "Load" для загрузки в Photoshop
7. Найдите панель "Фотозона Pro" в меню Плагины

### Для разработчиков:
```bash
# Клонировать
git clone <repo>
cd fotozona-pro

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Сборка
npm run build
```
